# Reports

`docs/reports` is one Bun package for every sprint report. Shared code lives at this root; each `sprints/NN/` folder (two digits) holds only that sprint's LaTeX, figures, and config. Lab reports live in `labs/NN/` the same way; scripts take them as `labs/NN`.

## Layout

- `scripts/` – generic TypeScript run by Bun. Every script takes the sprint first: `bun run <script> NN [...]`, resolved to `sprints/NN` (or `labs/NN` for a lab report). The list is in `package.json`.
- `preamble.tex` – shared by every sprint. `sprints/NN/main.tex` defines `\sprintname` and `\deliverable`, then runs `\input{../../preamble}`.
- `sprints/NN/report.config.ts` – the single source of everything sprint-specific: captured docs, part lists, review anchors, board URL, contracts folder, tickets, manual-check text. A lab report leaves out board, contracts, tickets, and manual checks. Sprint data goes here; scripts read it through `loadSprint`.
- `sprints/NN/demo.ts` – that sprint's app walkthrough for `capture-demo`.
- `check.config.ts` – lint overrides for this package, imported by the root `vite.config.ts`.

## Identity

Student names and full student IDs are private: they live in `.env` (shape in `.env.schema`) and reach LaTeX only through `build/identity.tex`, which `bun run identity NN` writes. In tracked `.tex` files write the macros `\studentOneName`, `\studentOneId`, `\studentOneTag` (last four digits) and the `Two` set. GitHub logins and the four-digit tags are public. Slot `One`/`Two` maps to a login in `scripts/lib/team.ts`.

Read env values only through `bunx varlock load` (masked). The `.env` file itself stays closed.

## Generated files

`content/part-a…e-*.tex`, `content/data/ac-table.tex`, `content/data/completion-table.tex` and `content/data/team.tex` start with `% Generated by`. Change the script or `report.config.ts`, then regenerate.

## Windows and macOS

Every script runs on both. Keep it that way:

- File output goes through Node `fs` from TypeScript; shell redirection (`>`) writes UTF-16 in PowerShell. `go-test` exists for this reason.
- Browsers launch the installed Chrome, then Edge (`scripts/lib/browser.ts`); no Playwright download.
- Fonts are Times New Roman and Courier New, present on both. A character neither has shows in `check-report` as a missing font glyph; rephrase it in ASCII.

## Package scripts

Script names stay clear of `build`, `dev`, `test`, `generate`: `vp run -r` and CI run those in every workspace, and these scripts need LaTeX, Docker, or network.

## Done

A report change is done when `bun run pdf NN` succeeds and `bun run check-report NN` prints `clean`, then the root lint, format, and check pass.
