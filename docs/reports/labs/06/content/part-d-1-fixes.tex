\partsection{D.2}{Fix of \#86: whitespace-only text (PR \#92)}

Branch \texttt{fix/reject-blank-claim-text}, author \texttt{beambeambeam}, \href{https://github.com/beambeambeam/claimflow/pull/92}{PR \#92}.

The contract adds a non-blank \texttt{pattern} to the four text fields. The pattern lists the JavaScript \texttt{\textbackslash s} set as \texttt{\textbackslash uXXXX} escapes, because Go RE2 \texttt{\textbackslash s} matches ASCII only; kin-openapi rewrites \texttt{\textbackslash uXXXX} to \texttt{\textbackslash x\{XXXX\}}, so the API and the form refuse the same text.
The API answers 400 naming the field and the rule \texttt{pattern}, with the F-02 §1.4 message. The form checks the same set with \texttt{/\textbackslash S/u} and the same messages, and sends no request.

\partsection{D.3}{Fix of \#87: double-click on Submit (PR \#91)}

Branch \texttt{fix/prevent-double-submit}, author \texttt{beambeambeam}, \href{https://github.com/beambeambeam/claimflow/pull/91}{PR \#91}.

\texttt{submit} returns early while \texttt{form.state.isSubmitting} is true. TanStack Form sets it before its first \texttt{await}, so it already holds for a second click in the same tick.
